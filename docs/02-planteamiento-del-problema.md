## Descripción del problema

Versión enviada (Intu, 2026-10-19). El equipo suavizó causalidad y alcance respecto al borrador del 17.

**Párrafo A — identificación:**

En el crecimiento del cultivo, los caficultores pueden notar cambios extraños en las hojas, opacidad, deterioro u otras alteraciones y pueden recurrir a su experiencia para interpretar lo que observan. Esta interpretación puede resultar difícil cuando no se reconoce con certeza qué es lo que se observa ni cuándo conviene pedir una revisión técnica.

**Párrafo B — causas / por qué cuesta:**

Al caficultor puede costarle interpretar lo que observa en una hoja por las condiciones de observación. Según la hora del día, la luz del sol puede hacer que la misma hoja se vea distinta y oculte o confunda lo que realmente ocurre. Además, una fotografía no siempre permite observar la hoja desde varios ángulos: por arriba puede parecer sana y por abajo aparecer alteraciones. Si la alteración no se reconoce oportunamente, puede retrasarse la búsqueda de información o de una revisión técnica. La imagen por sí sola puede no ser suficiente para distinguir una enfermedad, suciedad o una plaga.

**Párrafo C — alcance:**

En este proyecto se busca brindar a los caficultores una orientación preliminar a partir de una foto de una hoja individual, para apoyar el reconocimiento de las categorías estudiadas y orientar una posible revisión técnica. No se trata de sustituir la experiencia ni de emitir un veredicto final: es un apoyo técnico que complementa lo que ya saben, para que tomen mejores decisiones incluida la de pedir revisión técnica cuando convenga.

**Delimitación experimental (tras el árbol):** el problema central se delimita a la dificultad para interpretar de manera consistente las alteraciones visibles en una hoja a partir de una fotografía. La consulta técnica es utilidad potencial; su efecto no se evalúa en este estudio.
